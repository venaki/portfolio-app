# v0.1.1 - UI 폴리싱 + 증권사 + 배포

## GitHub Pages 배포
- gh-pages 브랜치 배포 설정 (`--base-href "/portfolio-app/"`)
- 배포 가이드 문서 (`release/deploy.md`)

## 증권사 (Investment Banks)
- 설정에 INVESTMENT BANKS 섹션 추가 (추가/삭제)
- Transaction 모델에 broker 필드 추가 (기존 데이터 하위호환)
- 거래 추가/수정 모달에 증권사 선택 칩 추가
- 거래내역 카드에 증권사 뱃지 표시 (`[명의][증권사]`)
- 포트폴리오 보유종목이 증권사별로 분리 집계
- 포트폴리오 카드/테이블에 `[명의][증권사]` 뱃지 표시 (기존 시장 뱃지 대체)
- 종목 상세 모달(거래내역/실현손익)이 증권사별로 필터링

## 거래내역 필터 개선
- 전체/매수/매도 + 증권사 필터를 펼치기(`▼ 필터`) 버튼으로 통합
- 활성 필터가 있으면 버튼 강조 표시

## 대시보드 개선
- 수익률 라벨 변경: `어제` → `오늘`, `원금 대비` → `원금`
- AccountCard에 오늘 변동 (수익금+수익률) 표시 추가
- `ChangeRow` 공용 위젯 추출
- 총자산 KRW + USD를 같은 라인에 baseline 정렬
- 총자산과 수익 표시 간격 조정

## 포트폴리오 개선
- 합계 영역 추가 (평가금액 + 원금 + 수익금/수익률)
- Account 필터와 Market 필터를 같은 줄에 배치

## 기타자산 개선
- 자산 추가/수정 모달에 날짜 선택(DatePicker) 추가
- 카드 목록을 월별 그룹핑으로 변경 (거래내역과 동일 패턴)

## 입력 개선
- 숫자 입력 필드에 소수점 입력 지원 (`numberWithOptions(decimal: true)`)
- KRW 금액 표시 시 소수점 버림 처리 (`.round()` → `.truncate()`)

## UI 세부 조정
- 거래내역/기타자산 카드 폰트 사이즈 통일 (제목/금액 14px w700, 뱃지 11px)
- 포트폴리오 보유종목 카드 일간 수익률 폰트 강조 (14px, bold)
- 수익률 폰트 크기 확대 (12px → 14px, 대시보드/포트폴리오 합계)
- Market 필터(전체/미국/한국) 우측 패딩 추가
- 포트폴리오 합계 영역 상하 패딩 조정
- 설정 화면 로그아웃 상단 불필요 패딩 제거
- 프로젝트 전용 patch-note 스킬 추가 (`.claude/skills/`)

## 데이터 호환성
- Transaction 시트 범위 `A:Z`로 확장 (향후 열 추가 대응)
- Settings 저장 시 동적 행 수 계산
- Prices 시트에 FX(환율) 행이 없으면 자동 삽입

# v0.1.10 - 대시보드 분석 탭 + 추이 복원

## 대시보드 분석 탭
- 대시보드 상단에 `현황 / 추이 / 비중` 분석 탭 추가
- 기존 현황 화면은 유지하고, 추이/비중을 같은 컨텍스트 안에서 전환 가능하도록 구성

## 비중 분석
- `종목별 / 유형별 / 계좌별` 기준 비중 분석 추가
- 도넛 차트와 비중 리스트 제공
- 자산 합계 / 부채 / 순자산 요약 표시
- 부채는 도넛 비중에서 제외하고 별도 섹션으로 분리

## 추이 분석
- 현재 자산 상태를 `Snapshots` 시트에 기록하는 스냅샷 구조 추가
- 추이 탭에 자산/원금 선 그래프 추가
- `올해 / 1개월 / 3개월 / 6개월 / 1년 / 전체` 기간 토글 추가
- 스냅샷 기록 리스트를 접기/펼치기 및 페이지 이동으로 조회 가능하게 개선

## 최근 1년 추이 복원
- 과거 거래내역 기준으로 최근 1년 일별 스냅샷을 복원하는 기능 추가
- 실제 첫 거래일 또는 첫 기타자산일 이후 구간만 복원하도록 처리
- Google Sheets `BackfillTemp` 시트를 이용해 종목별 과거 가격과 환율을 조회
- 복원 결과를 `Snapshots` 시트에 bulk upsert 하도록 최적화

## 안정성 개선
- `Snapshots` 시트가 없으면 자동 생성되도록 마이그레이션 추가
- 백필 날짜 파싱을 시트 표시 형식이 아닌 원시 날짜 값 기준으로 처리
- 휴장일/주말 근처 과거 가격 조회 fallback 보강

# v0.1.11 - 인증·데이터 안정성 강화 및 앱 전반 리팩토링

## 인증
- Firebase 사용자 검증과 일회용 OAuth 인증 절차를 적용하고, 사용자별 인증 상태를 분리했습니다.
- 로그인 팝업 검증, 토큰 갱신, 로그아웃 및 계정 전환 처리를 개선했습니다.
- 이번 업데이트 후에는 다시 로그인하고 사용할 Google Sheets를 선택해야 합니다.

## 데이터와 계산
- 거래 시각·입력 순서를 보존하고 원화 매입원가와 이동평균 기준 실현손익 계산을 수정했습니다.
- 잘못된 입력, 중복 ID, 보유량을 넘는 매도와 대출 초과 상환을 검증합니다.
- 저장 실패와 외부 수정 충돌을 명확히 알리고, 시트 전환 중 이전 작업이 새 데이터에 반영되지 않도록 개선했습니다.
- 검증된 전체 백업 복원, 거래 CSV 내보내기, 과거 가격 CSV/JSON 가져오기를 지원합니다.
- 누락·오류 시세가 잘못된 손실이나 자산 추이로 기록되지 않도록 처리했습니다.

## 화면과 기능
- 거래·기타 자산 입력 폼을 통합하고 수정·삭제, 계좌 연결, 검색 오류 안내를 개선했습니다.
- 모바일 탭 이동과 편집 상태를 수정하고 전량 매도한 종목의 실현손익과 기타 자산 원장을 보강했습니다.
- 대시보드의 개요·추이·배분 화면을 분리하고 날짜 축, 음수 값, 데이터 출처와 계산 범위를 개선했습니다.
- 미국·한국 종목 검색 응답을 통일하고 한국 종목 코드의 앞자리 0을 보존했습니다.

## 개발과 배포
- 인증, 계산, 저장소, 상태 관리와 UI 회귀 테스트를 확충했습니다.
- 정적 분석·테스트·웹 빌드를 실행하는 CI를 추가했습니다.
- GitHub Pages와 Firebase Hosting의 기준 경로에 맞춰 별도 빌드를 생성합니다.
- Worker와 웹 앱을 같은 릴리스로 배포하도록 절차를 정리했습니다.

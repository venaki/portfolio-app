# v0.1.8 - 기타 자산 누적 통합 + 계정별 섹션 구분

## 기타 자산 누적 통합
- 기타 자산을 스냅샷 방식에서 누적(delta) 방식으로 전환
- 동일 이름+계좌+카테고리 기준으로 내역을 통합하여 잔액 표시
- 추가/수정 모달에 방향 토글 추가 (입금/출금, 매수/매도, 대출/상환, +/-)
- cash 카테고리 제거 (savings로 통합)

## 계정별 섹션 구분
- 포트폴리오, 기타자산 탭에 계정별 pill 스타일 섹션 구분선 추가
- 설정의 accounts 순서에 따라 섹션 정렬
- 카드 내 account 태그 제거 (섹션으로 대체)

## UI 개선
- 합계 금액 탭하여 KRW/USD 토글 (포트폴리오, 기타자산)
- 대출 내역을 거래내역에서 -로 표시

## 버그 수정
- OtherAssets 시트 범위 A:H → A:Z 확장 (time 컬럼 누락으로 수정이 저장되지 않던 문제)
- 대시보드 대출 상환 이중 차감 수정 (consolidatedOtherAssets로 통일)
- 기타자산 탭 합계에 USD 환율 미적용 수정

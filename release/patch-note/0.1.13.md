# v0.1.13 - 기존 화면 디자인 복원 및 한국 종목코드 호환성 수정

## 화면 복원
- 기능 리팩토링 과정에서 변경된 대시보드 카드, 추이·비중 화면, 설정, 거래내역, 입력폼, 모바일 하단 메뉴를 v0.1.10 디자인 기준으로 복원했습니다.
- 로그인, 데이터 검증, 저장 보호와 평가 계산 개선은 유지했습니다.
- 작은 화면에서는 큰 금액이 카드 밖으로 넘지 않도록 줄바꿈합니다.
- 자산 추가 시 기존 자산명을 검색하고 선택하는 자동완성을 복원했습니다.
- 데이터 오류는 간결한 안내와 전체 상세 목록으로 확인할 수 있습니다.

## 종목코드 수정
- 영문이 포함된 한국 6자리 종목코드를 잘못 거부하던 검증을 수정했습니다.
- 거래·시세 읽기, 입력, 시세 수식, 검색에서 같은 코드 형식을 지원합니다.
- 숫자 종목코드의 앞자리 0 복원과 유효하지 않은 데이터의 저장 제한을 유지했습니다.

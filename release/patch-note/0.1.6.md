# v0.1.6 - Workers OAuth로 영구 로그인 유지

## Google 로그인 영구 세션
- Firebase signInWithPopup → Cloudflare Workers 직접 OAuth flow로 전환
- Workers가 Google OAuth authorization code를 교환하여 refresh token 획득
- refresh token을 Cloudflare KV에 저장, access token 만료 시 자동 갱신
- 한 번 로그인하면 페이지 새로고침/토큰 만료와 무관하게 영구 유지
- 토큰 복원 우선순위: localStorage 캐시 → Workers refresh → 팝업 재로그인

## Workers 엔드포인트
- GET /auth/login — Google OAuth 리다이렉트
- GET /auth/callback — authorization code 교환 + postMessage로 앱에 토큰 전달
- POST /auth/refresh — refresh token으로 새 access token 발급
- POST /auth/migrate — pending → 실제 uid로 KV 키 이동
- POST /auth/revoke — 로그아웃 시 refresh token 삭제

## 기타
- 자동 시세 갱신 등 백그라운드 호출에서 토큰 만료 시 팝업 미표시
- 팝업은 사용자 명시적 액션(시트 연결 등) 시에만 표시

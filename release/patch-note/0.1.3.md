# v0.1.3 - 대시보드 By Type 뷰 + 거래내역 기타자산 통합

## 대시보드 By Type 뷰
- By Account / By Type 토글 추가 (SegmentedFilter)
- By Type: 미국주식 / 한국주식 / 예금 / 채권 / 현금 / 대출 / 기타 그룹별 카드
- 각 그룹 내 개별 종목의 평가금액, 수익금, 수익률, 일간 변동 표시
- 그룹 헤더에 소계 및 수익률 표시
- 평가금액 내림차순 정렬
- 뷰 모드 상태를 Riverpod provider로 관리 (탭 전환 시 유지)

## 거래내역에 기타자산 통합
- History 화면에 Transaction + OtherAsset을 날짜순 통합 타임라인으로 표시
- 마켓 필터에 '기타' 옵션 추가 (기타자산만 표시)
- 거래유형 필터에 '기타자산' 옵션 추가
- FAB 클릭 시 '주식 거래 추가 / 기타 자산 추가' 선택 바텀시트
- 기타자산 탭은 조회 전용으로 변경 (추가/편집 버튼 제거)

## 자산 추가 개선
- 자산명 입력 시 기존 자산명 드롭다운 자동완성
- 포커스 시 전체 목록, 타이핑 시 필터링

## 시세 갱신 개선
- GOOGLEFINANCE 강제 갱신 시 수식 셀만 변조 (불필요한 셀 접근 제거)
- 대기시간 설정 가능 (forceRefreshWait)

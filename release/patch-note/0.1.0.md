# v0.1.0 - Initial Release

## Google SSO & Sheets 연동
- Google 로그인 (OAuth 2.0)
- Google Sheets를 데이터베이스로 사용 (거래내역, 시세, 기타자산, 설정)
- 새 스프레드시트 자동 생성 (4개 시트 + 헤더 + GOOGLEFINANCE 수식)
- Google Drive 시트 선택 (on-demand 스코프 요청)

## 대시보드
- 총자산 카드 (KRW/USD 표시)
- 펼치기/접기: 어제 대비 변동, 원금 대비 손익, 원금 금액
- 환율 표시 (1 USD = ₩)
- 계좌별 자산 현황 (PC: 가로 3열, 모바일: 세로)
- 계좌별 서브카테고리 (미국/한국/기타)
- 수동 새로고침 + 자동 새로고침 타이머

## 포트폴리오
- PC: 테이블 레이아웃 (종목/현재가/수익/평단가/수량/평가금액/매입환율)
- 모바일: 카드 레이아웃
- 계좌 필터 (pill 스타일) + 시장 필터 (underline 스타일)
- 기타자산 표시 (기타 필터)
- 종목 탭 시 거래내역/실현손익 모달

## 거래내역
- 월별 그룹핑, 날짜 내림차순 정렬
- 계좌 필터 (pill) + 전체/매수/매도 (pill) + 전체/미국/한국 (underline)
- 거래 추가: 종목 자동완성 (기존 종목 드롭다운 + CORS 프록시 검색)
- 거래 편집/삭제
- 매수(파란색)/매도(빨간색) 뱃지

## 기타 자산
- 예금/채권/대출/현금/기타 카테고리
- 계좌 필터 (pill 스타일)
- 합계 표시 (대출 음수 처리)
- 자산 추가/편집/삭제

## 실현손익
- 포트폴리오 종목 탭 시 모달 내 실현손익 탭
- 기간 필터 (전체/1개월/3개월/6개월/1년)
- FIFO 평단가 기반 매도별 실현손익 계산
- USD 종목: USD + KRW 이중 표시
- 합계 표시
- 수수료 미포함 안내 문구

## 설정
- Google 계정 정보 + 로그아웃
- 명의(계좌) 관리 (추가/삭제)
- 강조 색상 선택 (6가지 프리셋)
- 자동 새로고침 간격 설정
- CSV 내보내기
- 연결 시트 변경
- 앱 버전 표시

## 반응형 레이아웃
- PC (>=768px): 사이드바 네비게이션
- 모바일 (<768px): 하단 탭바
- 최대 너비 1280px 제한

# v0.1.5 - 구글 로그인 세션 유지 + 버전 동적 표시

## 구글 로그인 세션 유지
- Cloudflare Workers에 OAuth refresh token 관리 엔드포인트 추가 (/auth/exchange, /auth/refresh, /auth/revoke)
- 로그인 시 refresh token을 Workers KV에 저장
- 페이지 새로고침/토큰 만료 시 Workers를 통해 자동 갱신 (팝업 없음)
- access token을 localStorage에 캐싱하여 새로고침 시 즉시 복원
- 토큰 복원 우선순위: localStorage 캐시 → Workers refresh → 팝업 재로그인
- 로그아웃 시 Workers의 refresh token도 함께 삭제

## 버전 표시 개선
- 설정 화면 버전을 하드코딩에서 package_info_plus로 변경
- pubspec.yaml의 version 필드에서 자동으로 가져옴

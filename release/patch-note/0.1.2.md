# v0.1.2 - Firebase Auth + UI 개선 + 한국주식 개선

## Firebase Auth 연동
- Firebase Auth `signInWithPopup`으로 Google 로그인 (웹 전용)
- Firebase가 세션을 IndexedDB에 저장하여 새로고침 후 재로그인 불필요
- `authStateChanges()` 스트림으로 인증 상태 관리
- 로그인 시 Spreadsheets + Drive 스코프를 한번에 요청 (별도 스코프 요청 제거)
- 웹에서 `google_sign_in` 의존 제거, Firebase Auth로 통일
- Firebase Hosting 배포 (OAuth auth handler용)
- dev mode에서는 Firebase 초기화 스킵 (기존 DEV_MODE 동작 유지)

## 필터 상태 유지
- 탭 전환 시 필터/토글 상태 유지 (Riverpod StateProvider)
- Portfolio: 계정 필터, 시장 필터
- History: 시장/계정/매수매도/증권사 필터, 필터 확장 토글
- Assets: 계정 필터
- 페이지 새로고침 시 초기화 (메모리 전용)

## 한국주식 개선
- 종목코드 6자리 정규화 (Sheets가 앞자리 0 제거하는 문제 대응)
- 거래 추가/수정 시에도 한국 종목코드 6자리 정규화 적용
- Prices 시트에 한국 종목코드 텍스트 접두사(`'`) 추가로 0 보존
- 종목 검색 시 한국주식은 종목명으로 검색/표시, 미국주식은 티커로 검색
- 거래 추가/수정 라벨: 미국 '티커', 한국 '종목코드'로 구분
- 시장 선택: 미국/한국 → 한국 선택 시 거래소(KRX/KOSDAQ) 2단계 선택

## 대시보드 개선
- 새로고침 버튼에 로딩 인디케이터 표시
- 시세 업데이트 완료 시 SnackBar 알림
- 새로고침 버튼 클릭 시 GOOGLEFINANCE 수식 강제 갱신 (수식 변조→복원으로 캐시 클리어)

## UI 개선
- 모바일 하단 탭바에서 텍스트 제거, 아이콘만 표시 (높이 62→52, 아이콘 18→20)
- 거래내역 탭 아이콘 변경 (`schedule` → `receipt_long_outlined`)
- 반응형 breakpoint 768px → 1024px로 변경 (전체 화면 통일)
- 보유종목/거래내역 카드에 한국/미국 시장 배지 추가

## 버그 수정
- 설정에서 시트 변경 후 메인 화면으로 복귀하지 않는 버그 수정 (`Navigator.canPop` + `pop`)
- GOOGLEFINANCE 환율 수식에서 불필요한 `"price"` 속성 제거
- FX 행 수식을 `=GOOGLEFINANCE("CURRENCY:USDKRW")` (속성 없이)로 수정

## 데이터 개선
- Settings 시트에 `exchange_rate` 행 추가 (`=GOOGLEFINANCE("USDKRW")` 수식)
- 한국 주식 가격 조회 시 KRX/KOSDAQ IFERROR로 양쪽 거래소 자동 시도
- Prices/Settings 읽기 시 `UNFORMATTED_VALUE` 옵션으로 정확한 숫자값 수신

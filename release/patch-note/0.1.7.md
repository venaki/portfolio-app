# v0.1.7 - 거래 시간 기록 + 자산 순서 편집

## 거래 시간 기록
- Transaction, OtherAsset에 시간(time) 필드 추가
- 거래 추가/수정 모달에 시간 입력 UI 추가
- 거래 내역에 시간 표시
- holdings_engine에서 날짜+시간 기반 정렬

## 대시보드 계좌 순서 편집
- By Account 카드가 Settings의 accounts 순서대로 표시
- Settings > ACCOUNTS 섹션에서 드래그 핸들로 순서 변경 가능
- 변경된 순서는 Google Sheets Settings에 저장

## 포트폴리오 자산 순서 편집
- 포트폴리오 탭 하단에 "순서 편집" 버튼 추가
- 편집 모드 진입 시 하단 탭바 숨김, 취소/저장 버튼으로 전환
- 드래그 핸들로 주식 표시 순서 변경
- 저장 시 holdingOrder가 Settings에 영구 저장
- 정상 모드에서도 저장된 순서에 따라 자동 정렬
